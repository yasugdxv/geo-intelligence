  ではなく、一語一句まで詰め、戦争回避の確実性を担保する合意を求めているが、現状その水準を

- イランはイラン核合意（JCPOA）に加え、弾道ミサイル開発や代理勢力への支援停止まで含めた

  ない。例えば、イランがオマーン等に地域共同のウラン濃縮の事業体を設置し、濃縮済みウランを

  濃縮を継続している」と主張でき、米国は国際社会に対し「イラン国内で単独に濃縮していない」

  原油をホルムズ海峡経由で輸出しており、封鎖は自国経済にとって自殺行為となる為である。
