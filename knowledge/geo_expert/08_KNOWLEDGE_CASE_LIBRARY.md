# Session 1 + Session 2 Case Library

## 重要な注意

以下は、専門家の思考プロセスを示すケース教材である。個別の因果説明、人物評価、主体の意図、内部力学は専門家仮説を含み、検証済み事実として他案件へ転用してはならない。

特にSession 2で扱ったTrump、Putin、Xi Jinping、Kim Jong Un等に関する評価は、人物の固定属性ではなく、分析の出発点として検証すべき仮説の例である。

# Session 1 Cases

## Case 1：国際海峡に関する通航料・保護発言

### 最初の着眼点

率の大きさではなく、国際海峡で料金徴収を正当化することが、既存の原則や他海峡への先例を作る点。

### 抽出した思考

- 数字より制度原則を見る
- 発言者の本来目的から、交渉カードとしての機能を考える
- 産業競争力という代替仮説も検討する
- 政権内の省庁、軍、産業、支持勢力を分ける
- 発言の撤回から、内部反対と政策の限界線を推定する
- 選挙、エネルギー価格、議会制約を重ねる

## Case 2：台湾による中国海警局の要求無視指示

### 最初の着眼点

声明の意味ではなく、実際に無視した後、現場で中国側がどう反応したか。

### 抽出した思考

- 発表、実施、反応を分ける
- 反応強度から本気度と緊張段階を測る
- 台湾内部を緊張回避派と強硬派へ分ける
- 中国側にも鏡像分析を行う
- 選挙と国内政治への影響を考える
- 公開情報で分からない内部反応は、具体的事象と仮説を持って専門家へ聞く

## Case 3：カナダ産品への関税措置

### 最初の着眼点

関税率ではなく、対象品目の経済的重要性、代替可能性、国内受益者。

### 抽出した思考

- ニッチ品目を含む対象リストから本気度を測る
- 業界ロビーの可能性を考える
- 産業所在地を州・選挙区・支持政党と結びつける
- 激戦州への利益配分を確認する
- 相手国の報復対象も同様に政治効果から読む
- モノの貿易だけが強調され、サービス貿易が省略されていないか見る

# Session 2 Cases

## Case 4：米国の対ロシア制裁強化

### GPTの初期的な浅い置き方

Trumpを「強い対ロ圧力を求めつつ、自らの運用裁量も維持したい主体」と置いた。

### 専門家からの修正ポイント

最初に疑うべきなのは、「そもそもTrumpは対ロ制裁を強化したいのか」という上位目的である。専門家は、TrumpがPutinとの関係や、強い意思決定権を持つ相手との直接交渉を好む可能性を、過去の行動から検証すべき仮説として提示した。

その場合、制裁強化を受け入れた事実だけから「対ロ強硬」を上位目的に置くと、分析のスタートラインを誤る。議会・強硬派等を納得させながら、運用裁量を残す落としどころを選んだ可能性も検証対象になる。

### 抽出した思考

- ステークホルダーのリストが正しくても、Key Stakeholderの「欲しいもの」を誤ると全体が歪む
- 今回の行動より、過去から積み上げた上位志向を先に確認する
- 制裁は目的ではなく、交渉カード・妥協・Signalingの可能性も検討する
- 誰に見せる行動かと、実際の制裁内容の強さを掛け合わせて読む
- Trumpの人物評価は事実化せず、過去事例で支持・反証する

## Case 5：米中AI半導体・輸出管理

### 専門家からの修正ポイント

「中国への圧力を残しつつ米企業の競争力を維持する」というIssue-levelの目的より上に、「米中関係をどのような状態にしたいか」というRelationship Preferenceを置くべきだという指摘があった。

専門家はTrumpについて「良好な米中関係を維持したい」という上位仮説を提示し、その下に、圧力維持、米企業の競争力、米国雇用、戦争回避、支持率・選挙等を階層化して考える例を示した。

### 抽出した思考

- Issue Objectiveより上位のRelationship Preferenceを見る
- 半導体、TikTok、EV等の異なる案件でも同じ上位志向が説明力を持つか検証する
- 安全保障官僚、商務、議会、企業等は、Key Stakeholderと異なる目的を持つ
- 企業の工場所在地・選挙区・ロビーは議員の立場を変え得る
- 中国側の直接・間接ロビー等も、根拠があれば検証対象にする

## Case 6：NATO・欧州防衛負担

### 専門家からの修正ポイント

「米国のNATO内影響力を維持する」という目的を、Trump本人と米国の他主体で同一視しない。専門家は、Trump本人はNATO影響力維持を上位目的としていない可能性を仮説として提示した。

一方、議会議員は有権者、戦争への忌避、防衛産業、選挙区の雇用、献金等から異なる立場を取る可能性がある。

### 抽出した思考

- 「米国」という一主体で目的を置かない
- 指導者と議会・産業の目的を分ける
- NATO支持／反対という表明だけでなく、選挙区、防衛産業、雇用、兵士負担を見る
- 同盟維持の是非は、代替に必要な軍事・財政コストまで含めて考える

## Case 7：「超党派」報道とメディアの扱い

### 最初の着眼点

「超党派」と書かれていること自体で与党全体の反乱等を推定せず、具体的に誰が参加しているかを確認する。

また、普段大きく扱わない種類のニュースがトップで扱われる場合、「なぜこのニュースを、このタイミング・大きさで扱うのか」という編集判断も分析対象になる。

### 抽出した思考

- ラベルではなく構成メンバーを確認する
- 党内での位置、支持関係を見る
- メディアも目的を持つ主体として扱う
- テレビの順番、紙面の位置・面積はProminenceの手掛かりになる
- デジタル記事だけではProminence情報が欠けるため、取得できないものを推測しない

## Case 8：Source of Sourcesと主流ナラティブとの差

### 専門家からの示唆

価値の高い情報源は、有名メディア一覧だけではなく、「信頼する分析者が毎日何を読んでいるか」に埋め込まれている可能性がある。

専門家は、主流メディアと真逆の情報に出会った時、それを即採用するのではなく、「え？」と引っかかり、読み直し・裏取りを行う思考例を示した。

### 抽出した思考

- 専門家が継続的に読むサイトをSource of Sourcesとして蓄積する
- 主流と異なる情報を、正解ではなくInvestigation Triggerとして扱う
- AIは大量ソースの読解よりも、重要度・差分の選別ロジックで価値が決まる
- 日次Top Nのような運用は実装アイデアであり、専門家の確定要件として扱わない

# 共通パターン

1. 最初に違和感を置く
2. Key Stakeholder / 意思決定構造を確認する
3. Key StakeholderのPersistent Preferenceと上位目的を過去から仮説化する
4. Observed ActionとのGapをAudience・Driving Forceで説明する
5. 周辺ステークホルダーへ広げる
6. 相手側にも鏡像分析する
7. SignalとSubstance、発言後の反応を証拠として使う
8. 選挙・制度・産業利害を重ねる
9. 必要ならメディアのSelection / Placement / Framingを読む
10. Source of Sourcesと主流ナラティブとの差を調査トリガーにする
11. 主シナリオを選ぶ
12. 反証条件を置く
13. 専門家質問へ変換する
14. 企業影響を経路で示す
