# Situation

2026年7月中旬、トランプ大統領がホルムズ海峡の通航安全に関して、米国がより強く関与する、あるいは米国が守る・管理するという趣旨の発言をした。一方で、通航保護の費用負担や課金に関する案（20%通航料案）を示した後、これを撤回したとも報じられている。表向きには、米国がイランによる通航妨害を抑止し、ホルムズ海峡の安全を守ろうとしているように見える。ただ、これを単に「米国が航行の自由を守る」ではなくどう読むべきか。

# Known Background

- 6月17日：米国とイランが暫定停戦で合意。ホルムズ海峡の再開と、今後60日間の協議枠組みを設定。
- 6月25日以降：商船への攻撃と米軍の報復が始まり、停戦が不安定化。
- 7月7〜8日：米国が制裁免除を撤回し、トランプ大統領が停戦終了を表明。
- 7月11〜12日：イランが海峡閉鎖・管理強化を打ち出し、軍事衝突が拡大。
- 7月13日：トランプ大統領が、米国をホルムズ海峡の「守護者」とし、20％負担案を提示。
- 7月14日：20％案を撤回し、代わりに貿易・投資による見返りを求める方針へ転換。

# Interview Breakdown Questions（分解質問）

## ②分解質問

**1. 言葉の選び方**
この発言の中で、まず気になる言葉や表現はありますか。たとえば、「守る」「管理する」「費用負担」「課金」といった表現に、何か意味を感じますか。なぜその言葉が気になりますか？

**2. タイミング**
なぜこのタイミングで、この発言が出たと見ますか。発言の前後に、確認すべきイベントや情勢はありますか。どの文脈を重く見るべきですか。なぜそれが重要だと思いましたか？

**3. 対象者**
この発言は、誰に向けたメッセージだと見ますか。国内向けなのか、相手国向けなのか、市場向けなのか、同盟国向けなのか、どう分けて見ればよいでしょうか。なぜ、その対象者を重く見るのでしょうか。

**4. 目的**
その相手に、何をさせようとしている、あるいは何を抑えようとしている発言だと見ますか。複数ある場合、どれを主目的として見ますか。なぜそれを主目的と思いますか？

**5. 本気度**
この発言が本気の政策行動なのか、交渉上・政治上の演出なのかは、何を見れば判断できますか。何が動いていれば、本気度が高いと見ますか。

## ③初期見立ての確認

いま伺った、言葉の選び方、タイミング、対象者、目的、本気度を踏まえると、改めてこの発言全体はどう読むべきでしょうか。どの要素を一番重く見ましたか。どこまで断定してよく、どこからは留保すべきですか。背景にどんな力学の流れがあるとみますか？

## ④さらに確認する質問

他にあり得る読み方はありますか。それぞれのシナリオが生まれる起点は何ですか？その代替シナリオが強くなるのは、どのような材料が出た場合ですか。逆に、何が出ればその見方は弱くなりますか。

## ⑤最後に聞く質問

では、今後このテーマを継続して見る場合、何をモニタリングすべきでしょうか。何が出たら、今の見立てを変えるべきですか。
