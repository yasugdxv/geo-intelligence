# Session 1 + Session 2 Thinking OS

## 位置づけ

本ファイルは、2026年7月31日のSession 1と2026年8月25日のSession 2から抽出した、再利用可能な思考パターンを整理したものである。個別ケースで語られた原因、人物評価、意図を検証済み事実として保存するものではない。

Session 1の「違和感→ステークホルダー→力学→仮説→反証→企業影響」という基本骨格を維持しつつ、Session 2では、その一段手前に「誰を起点に読むか」を追加した。

## 1. 分析の入口

### 1.1 最初の違和感を探す

専門家は、ニュース全体を均等に読むのではなく、通常のルールや従来方針から外れた言葉、行動、対象、欠落、撤回を探す。

着眼点：

- 数字より、その行為を正当化する原則
- 従来方針との不一致
- 対象になったものと対象外になったもの
- 声明と現場行動の差
- 発言後の撤回・修正
- 本来重要だが語られていない論点
- 表面上矛盾する二つの動き

### 1.2 基準線と比較する

違和感は、通常状態を知らなければ判断できない。法制度、国際ルール、政治制度、過去行動、歴史、産業・貿易構造を基準線として置く。

## 2. Key Stakeholderから始める

### 2.1 局面を実際に動かす／止める主体を特定する

全主体を横並びに分析する前に、この局面の方向を大きく変えられるKey Stakeholderがいるかを確認する。

見るもの：

- 制度上の最終決定権
- 実質的な統制力
- 拒否権・阻止能力
- 交渉条件を変更する力
- 実施機関を動かす力
- 相手が交渉相手として重視する度合い

Key Stakeholderは常に一人とは限らない。必要に応じて2～3主体程度を優先して深掘りする。意思決定が分散している場合は、その分散構造自体をモデル化する。

### 2.2 全主体を同じ深さで分析しない

Key Stakeholderの上位目的・意思決定様式を先に理解し、その主体の意思決定を支える、制約する、押し返す、利用する周辺主体へ広げる。

## 3. Persistent Preferenceと目的の階層

### 3.1 単発の発言を「本音」にしない

政治家・指導者は、局面ごとに異なる相手へ異なる発言をする。今回の発言だけから、その人物の本質目的を決めない。

Persistent Preferenceは、次の積み重ねから仮説化する。

- 過去の行動
- 繰り返される発言
- 交渉相手の選び方
- 危機時の優先順位
- 類似局面での選択
- 役職が変わった後も残る行動傾向

ただし、Persistent Preferenceは固定人格ではない。役職・環境・相手によって行動は変わり得るため、反証可能な仮説として管理する。

### 3.2 目的を階層で読む

- Ultimate Objective：最終的に守りたい地位、成果、状態
- Strategic / Relationship Preference：相手国・相手人物とどのような関係を望むか、どのような交渉様式を好むか
- Issue Objective：今回の争点で実現したいこと
- Observed Action：実際に言ったこと、行ったこと

Observed Actionが強硬でも、Ultimate Objectiveが強硬とは限らない。逆も同様である。

## 4. Preference-Action Gapを読む

### 4.1 反対の行動を取る理由を探す

Persistent PreferenceとObserved Actionがずれる場合、人物が「考えを変えた」と即断しない。局面でそう振る舞わせている力を確認する。

主なDriving Force：

- 有権者・支持者・支持団体
- 選挙区、州、地域
- 献金・資金提供者
- 産業・雇用
- 党内指導部・派閥・政敵
- 議会・制度・司法
- 官僚組織・軍
- 同盟国・相手国・第三国
- 市場、価格、インフレ
- メディア・世論

### 4.2 「ラベル」ではなく、そうさせる力を見る

「共和党」「民主党」「保守」「強硬派」「超党派」などは分析の入口にはなるが、説明ではない。

問い：

- その議員は誰か
- 選挙区はどこか
- 支持基盤は誰か
- どの産業・雇用と結びつくか
- 誰から資金・政治的支援を受けるか
- 党内で誰に近いか
- その行動で誰に利益・不利益が出るか

## 5. AudienceとSignal / Substance

### 5.1 誰に見せているのか

政治的発言・政策は、政策対象そのものだけに向けられているとは限らない。

候補：

- 有権者
- 支持団体
- 党内
- 大統領・首相など上位意思決定者
- 野党・政敵
- 同盟国
- 相手国
- 相手国内の特定勢力
- 産業界
- メディア・国際社会

一次Audienceと二次Audienceを分けてよい。

### 5.2 見せ方と実質を分ける

本気度は強い言葉だけで判断しない。

確認する：

- 実際の政策内容はどれほど具体的か
- 対象・適用範囲はどこまでか
- 強制性・拘束性はどの程度か
- 実施・執行が伴っているか
- 運用裁量・例外がどの程度残るか
- その行動に実質的なコストを払っているか

Audience仮説とAction Substanceを組み合わせ、SignalとSubstanceを分けて読む。

## 6. 国家・組織内部と関係の力学

### 6.1 国家を一枚岩として扱わない

指導者、官僚組織、軍、政党、議会、派閥、産業界、支持層は同じ目的を持たない。政策の矛盾や撤回は、異なる勢力の影響が交互に強まった結果として説明できる場合がある。

### 6.2 鏡像分析

一方の国だけを複雑に分析し、相手国を単純化しない。相手側にも強硬派・穏健派、合意派・非合意派、行動しないと弱く見える主体、妥協で権限を失う主体が存在し得る。

### 6.3 関係と力学

- 誰が誰を支持するか
- 誰が意思決定者へ影響するか
- 誰が政策を止められるか
- 誰が誰に依存するか
- 誰の力が上がると誰が困るか
- 合意すると誰が力を得るか
- 合意しないことで誰が利益を得るか
- 表向き対立していても、特定結果では利害が一致する主体はいるか

## 7. 発言ではなく反応を見る

声明の意味は、実施と相手の反応によって変わる。

分析単位：

1. 発表・声明
2. 実施・現場行動
3. 相手の反応
4. 国内外の反発
5. 撤回・修正
6. 次の行動

撤回は単なる取消ではない。誰が押し返したか、何が政策の限界線だったかを示す可能性がある。

安全保障事案では、反応をエスカレーション段階として考える。

- 黙認・無反応
- 外交的抗議
- 警告
- 非致死的威圧
- 接触・拘束・拿捕
- 威嚇射撃
- 限定攻撃
- 継続的軍事行動

## 8. 政治・経済の制約

政治家の行動は、理念だけではなく次に制約される。

- 選挙日程
- 議会構成
- 予算・法案承認
- 連立政権
- 支持率
- 激戦州・選挙区
- 支持産業
- 後継者
- 政治的レガシー
- 調査・弾劾・政権維持リスク
- 価格、雇用、インフレ

関税、制裁、規制では、率だけでなく対象品目・企業・地域を確認し、誰が利益を得るかを逆算する。

## 9. メディアと情報源を読む

### 9.1 メディアも主体である

ニュースの内容だけでなく、可能な範囲で編集判断そのものを見る。

- なぜこのニュースを選んだのか
- なぜ今なのか
- なぜこの見出し・言葉なのか
- なぜ「超党派」等の属性を強調したのか
- テレビで何番目に扱ったか
- 紙面でどの位置・どの面積だったか
- 小さく扱った／扱わなかった論点は何か
- 社説ではどう位置づけたか

紙面・放送順などのProminenceは編集意図の手掛かりになり得る。一方、デジタル記事ではこのメタ情報が欠けることがあるため、取得できない情報を推測しない。

### 9.2 Source of Sources

価値ある情報源は、有名メディアだけではない。信頼する専門家・分析者が日常的に何を読んでいるかは、重要な情報源選定シグナルである。

専門家が推薦・継続利用するサイト、分析者コミュニティで回覧される情報源を「Source of Sources」として蓄積する。

### 9.3 主流ナラティブとの差はInvestigation Trigger

メインストリームと真逆・大きく異なる情報は、正しさの証明ではない。「なぜ違うのか」を再確認し、裏取りするためのInvestigation Triggerとして扱う。

## 10. 仮説とストーリー

地政学的な意図や内部力学は、完全には確認できないことがある。そのため、最初から唯一の真実を探すのではなく、説明力のある仮説を作る。

基本手順：

1. 事実と観測を確認する
2. Key StakeholderとPersistent Preference仮説を確認する
3. 2～4個の局面仮説を置く
4. 目的、Preference-Action Gap、制約、タイミングとの整合を比較する
5. 主シナリオを選ぶ
6. 公開情報・専門家情報で検証する
7. 最も強い反論を考える
8. 新しい証拠で更新する

可能性を並べるだけでは意思決定支援にならない。主シナリオを示す一方、断定せず、変更条件を置く。

### 10.1 主シナリオを持つ

複数仮説を持つことは重要だが、分析やレポートでは、現時点で最も整合的な主シナリオを置く必要がある。

見るべきこと：

- どの観測を最も重く見るか
- Key StakeholderのPersistent Preferenceと整合するか
- 観測行動が逆方向なら、そのGapを説明できるか
- 他の仮説より主シナリオを優先する理由は何か
- どこまで言い切ってよいか
- 何が出たら主シナリオを変更するか

### 10.2 代替仮説は補足として管理する

代替仮説は、主シナリオを弱めるためではなく、見立ての検証可能性を高めるために扱う。

- 成り立つ条件
- 強まる材料
- 弱まる材料
- 主シナリオから切り替える条件

「いずれの可能性も否定できない」で終わらせない。

## 11. 専門家ヒアリング

広い一般質問ではなく、具体的事象と暫定仮説を渡す。

質問構造：

1. 具体的事象
2. 確認済み事実
3. Key StakeholderとPersistent Preferenceの暫定仮説
4. 今回のObserved ActionとのGap
5. 確認したい内部力学・Audience
6. 仮説が間違っている可能性
7. 次に見るべき兆候

仮説を支持するコメントだけを誘導しない。

## 12. 企業への接続

外部事象から企業影響へ飛躍しない。

外部事象
→ 政治・制度・市場・物流・世論・安全保障上の変化
→ 業界・地域への波及
→ 自社エクスポージャー
→ 意思決定・準備・モニタリング

直接影響が弱い場合は、重大リスクとして無理に結論化せず、環境変化、前提変更、確認論点として示す。

## 13. 避けるべき浅い分析

- ニュース要約だけで終わる
- 全ステークホルダーを同じ深さで並べる
- Key Stakeholderを見ずに周辺主体から分析を始める
- 今回の発言だけで人物の本質目的を決める
- Persistent Preferenceを固定人格として扱う
- Observed Actionと上位目的を同一視する
- 「共和党」「保守」「強硬派」「超党派」のラベルで説明を終える
- Audienceを考えずに発言を額面通りに受け取る
- 強い言葉を実質的政策強度と同一視する
- 国家を一人の意思として扱う
- 市場が落ち着いたためリスクが消えたと短絡する
- 選挙、議会、支持基盤、産業・雇用を見ない
- 声明後の現場行動を確認しない
- 関税率だけを見て対象品目を見ない
- メディアの編集意図を根拠なく断定する
- 主流と逆の情報を「正しい」とみなす
- 可能性を多数列挙し、見立てを示さない
- 仮説を支持する情報だけを集める
- 専門家へ抽象的な質問をする
- 事業影響を飛躍して作る
