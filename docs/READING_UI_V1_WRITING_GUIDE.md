# Expert Review Writing Guide（素材: 社内レビュー/アナリスト文 約25件を通読）

目的: 「書き方・着眼・思考パターン」の抽出のみ。事実は知識化しない。

## 1. 文章面
- **長さ**: 書き手本人のコメントは2〜4文・100〜300字が標準。長くても1段落。長文は引用側(アナリスト原文)に置き、本人の読みは短く刺す。
- **結論の置き方**: 冒頭に置くより「気になった点→読み」の順が多い。数字付き箇条の要約では最終項に「結論：〜可能性が高い」と置く。見出し相当は短い名詞句か結論一文。
- **書き出し**: 「〜の件ですが」「これは新しいですね」「〜は妙だなと思っています」など、観察・反応から入る。「各位」以降の前置きは1文で済ませる。
- **断定の強さ**: 事実の評価は断定、将来は「〜可能性が高い／〜と思える次第です」。確信が弱い箇所は「〜のではないか」「〜かもしれない」と明示的に弱める。強弱を一段落内で混ぜる。
- **語尾の使い分け**: 観察=「〜ですね」、読み=「〜と思います／〜と思える次第です」、疑問=「〜ではないか／〜とはこれ如何なりや」、条件=「〜であれば〜」、補足=「（←無理）」等の短い括弧。
- **一般論との差分**: 「一般的には〜」「通説は〜」と先に置き、「ただ今回は〜」で差分を出す。差分は1点に絞る。
- **主語**: 人物・組織(トランプ、イラン、軍、企業)を主語にすることが多く、「状況」「構造」主語は少ない。動機・利害・面子で語る。
- **因果**: 「〜だから」より「〜なら〜のはず／〜の事情を考えると〜」と利害から逆算して繋ぐ。因果の飛躍は「と考えると」で一拍置く。
- **違和感の表現**: 「妙だ」「何故〜？」「〜は不自然」「言ったもん勝ちの面がある」。疑問形のまま残して終えることもある。
- **シナリオ展開**: 3択(A/B/Cの案)＋「最有力は〜、理由は〜」、または観測指標(何を見れば分かるか)を列挙。確率の数値化は少なく、「高い/低い」で表す。
- **避ける表現**: 「〜と言える」「〜を示唆している」「〜の観点から考察する」「本稿では」「総じて」など論文調・評論調、全方位の両論併記、固有名詞と数字の羅列。

## 2. 思考面（型の有無と頻度の印象）
- **A型 違和感→立場・思惑→別の筋書き→注視点**: 実在、最頻出。典型「〜なのに〜なのは何故か」「相当準備されていたことは明らか」「〜と考えると〜に備えているように見える」。
- **B型 一般的見方→行動が不自然→本人の利害なら別説明→したがってこう読む**: 実在、2番目。典型「通説は〜。だが〜の理屈では温存が得」「〜を見ると、むしろ〜」。外部アナリストも多用(「支配的な見方は〜、我々は反論」)。
- **C型 誰に有利/不利→誰が変えるインセンティブを持つか→力学→別シナリオ**: 実在するが、本人コメントよりアナリスト原文に多い。典型「漏れるのは止めたい勢力がいる時」「〜しない限り譲歩する理由がない」。
- **追加の型**
  - D「観測指標列挙型」: 動く前に見るべき資産・日程・発言を並べ、時期を絞る。
  - E「根本問い返し型」: 「なぜ〜が〜で得られなかったものを〜で手放すのか」と、前提の置き方を問う。
  - F「真偽・情報源の慎重型」: 発信主体の動機や検証の有無を先に疑う。
  - G「長期化/時間稼ぎ読み型」: 表の説明と別に、時間・準備・在庫の観点から読む。
  - H「段階的結論型」: 数字付き箇条で論点→争点→持続性→結論。

## 3. 汎用テンプレート（UIカード本文2〜4文用）
書き出し
1. 「〜という説明が一般的ですが、〜の点は少し引っかかります。」
2. 「表面上は〜ですが、〜の動きは説明がつきにくいですね。」
3. 「まず気になるのは、〜がなぜ今〜なのかという点です。」
4. 「〜は想定の範囲内ですが、〜だけは想定外です。」
5. 「通説とは別に、〜側の事情から見ると違う姿が見えてきます。」
つなぎ
6. 「〜の立場に立つと、〜を優先する理由があるはずです。」
7. 「仮に〜が目的なら、〜という動きは筋が通ります。」
8. 「〜と考えると、〜の見え方が変わってきます。」
9. 「一方で、〜にとっては〜が得になる構図でもあります。」
10. 「問題は、誰が〜を変えるインセンティブを持つかです。」
11. 「〜がない限り、〜が譲歩する理由は乏しいと思います。」
語尾・結論
12. 「〜と読むのが自然ではないでしょうか。」
13. 「〜の可能性は否定できませんが、現時点では〜の方が有力だと思います。」
14. 「したがって、〜よりも〜を前提にしておくのが妥当と考えます。」
15. 「〜と思える次第です。」
16. 「断定はできませんが、〜の筋が強いと見ています。」
今後の注視点
17. 「今後は〜が出るかどうかが分かれ目になります。」
18. 「見るべきは〜の有無で、〜なら別シナリオに切り替えます。」
19. 「当面の確認点は〜と〜の2つです。」
20. 「〜が動いた場合は、〜側のシナリオを優先します。」
違和感・留保
21. 「正直なところ、この点は〜と言い切れず、疑ってかかる必要があります。」
22. 「〜の発信は動機も含めて割り引いて見ています。」
