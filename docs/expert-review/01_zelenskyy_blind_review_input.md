# Blind Expert Review — Part A 入力資料

**この資料にはAIの分析・解釈は一切含まれていません。** 含まれるのは、実際に確認された
発言・行動・時系列・報道の事実関係のみです（発言の引用は誰が述べたか・匿名か実名かを
明記していますが、その発言の「意図」についての解釈・推測は含んでいません）。

## 資料選定について(Facilitator向け・専門家にも開示してよい)

以下のTimeline・発言・Sourceは、**AIの分析が重視した項目を基準に選んだものでは
ありません**。実際に確認できた一次情報・報道を、立場(米/ウクライナ/ロシア/欧州/
第三国/専門家データ)ごとにバランスよく含めることを基準に選定しています。ISW・
ACLEDも「AIが重視したから」ではなく、この局面の理解に一般的に必要な専門家評価・
データとして掲載しています。相反する情報(例: 匿名情報源による因果主張と、
専門家データによるhedge付き評価)は、どちらが正しいかを示唆せず両論併記して
います。本資料に含めなかった情報は末尾「本資料に含めなかった情報」に記録して
います。

## Facilitator向け進行ルール

- 回答は**自由記述**としてください。Q1〜Q17は思考を漏れなく引き出すための
  プロンプトであり、評価尺度(Agree/Disagree等)は使いません。
- 望ましい順序は、専門家自身の言葉で: **Key Point → Key Players → Actorの目的・
  Priority → 重要Evidence → Scenario**、という流れで自然に語ってもらうことです。
  Q1〜Q17は、この流れの中で漏れた論点を後から補うために使ってください。
- 回答が終わるまでAI分析(Part B)は一切見せないでください。

## Blind Expert Questions

以下の質問に、上記資料のみに基づいて回答してください(自由記述、評価尺度は使い
ません)。

**Q1. Primary Key Point**: この局面を見るうえで、最も重要なKey Pointは何ですか？

**Q2. Why**: なぜそこをKey Pointと考えますか？

**Q3. Alternatives**: 他にどのKey Point候補を考えましたか？なぜ最終的には採用しません
でしたか？

**Q4. Control Structure**: この局面を実際に動かすものは何ですか？(特定Actor／制度／
構造要因／複数Actor／その他)

**Q5. Key Players**: 重要なKey Playerは誰ですか？その中でも特に重要なActorは誰ですか？

**Q6. Actor Objective / Priority**: 各主要Actorについて、長期的に何を達成したいのか、
今回何を最も優先しているのかを教えてください。

**Q7. Stated vs Real Preference**: 表向きの主張と、実際に取りたいものは同じですか？
違う場合、何を本当に取りたいと考えますか？

**Q8. Intrinsic vs Instrumental**: その要求自体が目的なのか、交渉カードなのか、両方
なのか？

**Q9. Red Line / Tradeable**: 何は譲れないか？何なら取引可能か？

**Q10. Constraint / Leverage**: Actorを制約しているものは何か？相手に対して使える
Leverageは何か？

**Q11. Media / Information Signal**: 今回の報道・匿名情報・発言について、特に意味が
あるものは何ですか？逆に、あまり重視しないものは何ですか？

**Q12. Evidence Weighting**: 今回の判断で最も重視したEvidenceは何ですか？なぜその
Evidenceを重視しますか？どのEvidenceは信頼度を下げて見ていますか？

**Q13. Alternative Interpretation**: 現在の見方とは別に、合理的なAlternative
Interpretationはありますか？

**Q14. Scenario**: ここから考えられる主要Scenarioは何ですか？

**Q15. Scenario Hinge**: 何が起きればScenarioが切り替わりますか？

**Q16. Leading Indicators**: 今後何を観測すれば、Scenarioの方向性を早く判断できます
か？

**Q17. Missing Information**: 現時点で足りていない情報は何ですか？追加で調べるなら
何を調べますか？
