# Stakeholder & Force Model

## 1. 目的

Case／ThemeのFoundation Pack・地政学ナレッジDBに既にある情報（Entity、Relationship、
Dependency、Asset、Leverage Card、actor_profile等のFoundation Knowledge、Claim）を
最優先の根拠として使い、そこで足りない範囲だけを、案件ごとの「暫定ステークホルダーモデル」
として補うための参照ガイド（01_SYSTEM_POLICY.md 絶対原則5の根拠優先順位を参照）。
DBに十分な情報が無い場合は、推測で埋めず不足情報として構造化して返す。

Session 2を受け、全主体を横並びに並べるモデルから、「Key Stakeholder→上位目的→局面行動→周辺Driving Force」へ分析を広げるモデルへ更新する。

## 2. Key Stakeholderの選定

### 2.1 最初に確認すること

この局面を実際に動かす／止めるKey Stakeholderがいるか。

候補を比較する軸：

- 公式な最終決定権
- 実質的な支配・統制力
- 拒否権・阻止能力
- 交渉条件を変える力
- 政策を実施させる力
- 他主体がその人物・組織の反応を基準に動く度合い

Key Stakeholderが明確な場合は1～3主体程度を優先して深掘りする。明確でない場合は、議会、連立、官僚、軍、裁判所等に権力が分散している構造を示す。

### 2.2 Key Stakeholderを「役職名」だけで選ばない

大統領、首相、党首が常に最重要とは限らない。制度上の権限とDe factoの影響力を分ける。

## 3. ステークホルダーの分解単位

- 国家
- 指導者
- 政権中枢・側近
- 省庁・規制機関
- 軍・治安組織
- 政党・議会
- 党内派閥・議員グループ
- 産業界・業界団体・ロビー
- 地域・州・選挙区
- 献金・資金提供ネットワーク
- 支持層・有権者・国民
- 同盟国・競合国
- 国際機関
- NGO・市民団体
- 武装組織・代理勢力
- 企業・競合
- メディア

全主体を網羅せず、今回事象を説明するために影響力がある主体を選ぶ。

## 4. Key Actor Profile

Key Stakeholderについては、通常のStakeholder Tableより深く確認する。

| 項目 | 確認する内容 |
|---|---|
| 公式な役割 | 制度上何を決め、実行できるか |
| 実際の影響力 | 非公式に誰へ影響できるか、誰が反応を基準に動くか |
| Ultimate Objective | 最終的に守りたい地位、成果、状態 |
| Persistent Preference | 複数の過去行動から推定する比較的持続する志向。仮説として保持 |
| Historical Evidence | Persistent Preferenceを支える過去の行動・発言・交渉事例 |
| Counter Evidence | 上記仮説に反する行動・発言 |
| Strategic / Relationship Preference | 相手国・人物との関係、交渉様式、意思決定様式への志向 |
| Issue Objective | 今回の争点で実現したいこと |
| Observed Action | 実際の発言・政策・行動 |
| Preference-Action Gap | 上位志向と今回行動の一致・不一致 |
| Primary Audience | 最も強く見せようとしている相手の仮説 |
| Secondary Audience | 二次的な受け手の仮説 |
| Supporting Base | 有権者、支持団体、党内、資金、軍、産業等 |
| Political Calendar | 選挙、任期、予算、党大会、後継者 |
| Economic / Industry Drivers | 産業、雇用、貿易、資源、価格 |
| Institutional Constraints | 議会、裁判所、官僚組織、法制度、連立等 |
| External Constraints | 同盟国、相手国、第三国、市場等 |
| Leverage | 軍事、制裁、市場、技術、資金、世論、同盟 |
| Vulnerability | 依存、国内対立、選挙、財政、価格感応度 |
| Red Line | 受け入れにくい条件 |
| Confidence | 上記評価の確度 |

Persistent Preferenceは人物の属性として固定せず、Historical EvidenceとCounter Evidenceをセットで更新する。

## 5. 周辺主体ごとに整理する項目

| 項目 | 確認する内容 |
|---|---|
| 公式な役割 | 制度上何を決め、実行できるか |
| 実際の影響力 | Key Stakeholderや実施機関へどう影響するか |
| 本質的目的 | 最終的に何を実現したいか |
| 現在の優先順位 | 今、何を他より優先しているか |
| 避けたい事態 | 何が起きると損失・失脚・弱体化するか |
| Audience | 誰に何を見せたいか |
| 交渉上欲しいもの | 公開要求と実質要求 |
| 譲歩可能なもの | 交換可能なカード |
| レッドライン | 絶対に受け入れにくい条件 |
| 支持基盤 | 政治、資金、軍、産業、社会上の支持者 |
| 政治日程 | 選挙、任期、予算、党大会、後継者 |
| 経済利害 | 産業、貿易、資源、雇用、価格 |
| 権限・権益 | 組織として維持したい地位・予算・権限 |
| 歴史的ドライバー | 過去の事件、屈辱、犠牲、成功体験 |
| 感情的ドライバー | 不信、恐怖、威信、報復意識。根拠がない場合は不明 |
| レバレッジ | 軍事、制裁、市場、技術、資金、世論、同盟 |
| 脆弱性 | 依存、国内対立、選挙、財政、価格感応度 |
| 拒否権 | 誰の行動を止められるか |

## 6. Audience Matrix

発言・政策ごとに、可能な範囲で次を整理する。

| 発言・行動 | Primary Audience | Secondary Audience | 伝えたいメッセージ仮説 | 実質的Action Substance | 確度 |
|---|---|---|---|---|---|

Audienceは事実ではなく仮説である。根拠となる支持基盤、選挙、過去発言、政策対象、タイミングを併記する。

## 7. 関係性の種類

- 支持
- 反対
- 指揮・統制
- 影響
- 資金提供
- 依存
- 競合
- 協力
- 交渉
- 拒否権
- 代理関係
- 歴史的対立
- 一時的な利害一致
- Audience / Signaling

敵・味方は固定属性にしない。安全保障では協力し、貿易では競合するなど、テーマごとに関係が変わる。

## 8. 力学を説明する問い

- 誰がこの局面を最終的に動かせるか
- Key Stakeholderの本来の志向と今回行動は一致しているか
- 一致しない場合、誰・何がそうさせているか
- 誰に見せるための行動か
- 誰の力が上がると、誰が困るか
- 合意すると、国内の誰が強くなるか
- 合意しないことで、誰が権限や予算を維持できるか
- エスカレーションで利益を得る主体はいるか
- 表向き対立している主体の間に、結果に対する利害一致はあるか
- 何をしないと「弱く見える」主体がいるか
- 誰が公式決定権を持ち、誰が実行を左右するか
- 誰が政策を押し返せるか
- 「党派」「思想ラベル」の中で、実際の支持基盤・選挙区・産業・献金はどう違うか

## 9. ケース内モデルの出力形式

### Key Actor Card

| Key Actor | Ultimate Objective | Persistent Preference | Historical Evidence | Issue Objective | Observed Action | Preference-Action Gap | Primary Audience | 主なDriving Force | 確度 |
|---|---|---|---|---|---|---|---|---|---|

### Surrounding Stakeholder Map

| 主体 | 目的 | Key Actorへの影響 | 支持基盤・利害 | Audience | 制約・恐れ | レッドライン | 確度 |
|---|---|---|---|---|---|---|---|

Key Stakeholderが不在の場合は、意思決定ノードと拒否権を複数示す。

## 10. 時間変化への対応

主体の公式役割、優先順位、関係性、交渉条件は時点を明示する。

- 比較的安定：政治制度、組織の基本役割、地理、長期的歴史
- 準構造的：指導者、派閥、同盟、支持基盤、Persistent Preference仮説
- 現在状態：交渉条件、支持率、制裁、軍事態勢、直近発言、Audience
- 仮説：意図、隠れた関係、次の行動予測

古い情報を現在の状態へ自動継承しない。Persistent Preferenceも反証や役職変更で更新する。
