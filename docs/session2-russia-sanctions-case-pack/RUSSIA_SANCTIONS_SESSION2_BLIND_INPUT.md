# Situation

米国の対ロ制裁強化法案が2026年に前進した。中心的な見立て（Speaker3側の初期分析）は、
「対ロ制裁を法律として固定したい議会」と「制裁の使い方は自分で決めたいTrump政権」の間で
妥協が成立した結果とみるのが最も整合的、というもの。

# Known Background

- 2025年案は上院で85人の共同提案者を集めたが、Trump政権の支持を得られず停滞した。
- 2026年案では、第三国への関税を500％級から最大100％に下げ、対象を絞る一方、大統領に
  制裁の適用除外や解除の裁量を広く残した。
- White Houseは、この大統領裁量を支持理由として明示した。
- 重要な変化は、法案が「Trumpを縛る制裁」から「Trumpも使える圧力手段」に変わったこと。
- Counterfactual: 議会支持の強さだけが決定要因なら、2025年にも進んだはずである。したがって
  見るべきは、なぜTrump側が反対を外したのかである。
- 防衛・エネルギー業界等が今回の条文修正を直接動かしたとの十分な証拠は、現時点では確認できない。

## 本当の綱引き（初期分析）

1. **制裁の「制度化」vs 大統領の「運用裁量」**: 議会側はTrumpが積極的に動かなくても一定の
   対ロ圧力が残る制度を作りたい。Trump側は制裁は持ちたいが「いつ使うか」「いつ解除するか」は
   自分で決めたい。妥協として、議会は制裁の法制化を確保し、Trumpは適用除外・解除などの
   広い裁量を確保した。
2. **第三国関税で双方の利害が一致**: 議会側は中国・インド等のロシア産エネルギー購入を抑え
   ロシアの収入を削りたい。Trump側は第三国への関税を外交上の圧力手段として持ちたい。
3. **関税反対派は法案全体を止められなかった**: 第三国関税を削除する修正案には32票が入ったが
   否決され、法案全体は86対11で上院を通過した。

## 着地点（初期分析）

議会は「制裁を法律にすること」を得た。Trumpは「制裁の使い方を決める裁量」を得た。これが
今回の妥協の核心とみる。
