# Phase R1 Human Check用 新規5ケース（質問文のみ、freeze）

2026-09-03作成。ユーザー設計。Chunk6のブラインド5ケース（高市/NATO/TSMC/EU/南シナ海）とは
重複しない、別テーマの新規5件。目的はAcceptance Criteriaの自動判定ではなく、**専門家が
「どう考えたか」を人手で評価するため**の素材。評価者向けの「評価上の狙い」はこのファイル
にのみ記載し、Expert AIへの実行プロンプトには一切含めない（下の引用ブロックのみを投入する）。

## 評価順（ユーザー指定）

Case 1 → 3 → 2 → 4 → 5（Structural/Institutionが比較的素直な案件から始め、Actor、最後に
Frame-breaking・Narrative divergenceまで難度を上げる構成）。

## Human Check採点項目（5項目、全ケース共通の尺度）

1. Key Pointは正しいか
2. 重要Actorの抜け/過剰はないか
3. Evidence以上に推論していないか
4. 深掘りの深さは適切か
5. この分析を専門家として採用するか

## Case 1｜中国の重要鉱物・レアアース輸出管理

**評価上の狙い（Expert AIには渡さない）**: Structural / Institution。単純な「中国が資源を
武器化している」で終わらず、輸出許可制度、供給集中、企業在庫、代替供給能力、米日欧の政策
対応のどこが本当のKey Pointかを発見できるかを見る。逆張り不要ならSurface/Structuralで
止まれるかも確認。Entity紐付けは意図的になし（Institution/Structural発見を、事前タグ付け
なしで自力にさせるため）。

> 中国によるレアアース、永久磁石、ガリウム・ゲルマニウム等の重要鉱物・素材に関する輸出管理と、
> それに対する米国・日本・欧州の対応をめぐる現在の局面について分析してください。
>
> 最新の公開情報を確認した上で、
>
> - この局面を実際に動かす・止める主要な意思決定主体
> - 各主体の上位目的、現在の目的、制約、利用可能なカード、レッドライン
> - 制度・許認可・サプライチェーン構造のうち、実際に結果を左右している要因
> - 現在の力学
> - 最も重要なKey Point（局面の蝶番）
> - 主シナリオと、重要な代替シナリオ
> - 今後方向性が変わったことを示すObservable Indicators
>
> を整理してください。
>
> 表面的な「米中対立」「資源の武器化」という説明を前提にせず、それで十分説明できる場合は
> 無理に別の仮説を作らず、Actor、Institution、Structuralな要因を比較した上で最も説明力の
> 高い見方を採用してください。
>
> Evidenceが不足している場合は、不足を明示し、結論に必要な追加調査を実施してください。

## Case 2｜サウジ・米国・イスラエルの関係再編

**評価上の狙い**: Actor Intelligence。MBS、米政権、イスラエル首相などの「表明された政策」
より、何を本当に取りたいのか、何を譲れないかから局面を読めるか。10 Key Actorのうち
MBS/Trump/Netanyahuの3名が関与する構成のため、entity紐付けあり。

> サウジアラビア、米国、イスラエルの間で進む安全保障・外交関係の再編について、現在の局面を
> 分析してください。
>
> 特に、サウジアラビアとイスラエルの関係正常化、安全保障保証、防衛協力、原子力協力、
> パレスチナ問題、イランへの対応などが相互にどう結びついているかを対象としてください。
>
> 最新の公開情報を確認した上で、
>
> - 局面を動かすKey Actorsは誰か
> - 各Actorの長期的な上位目的と、この局面で実際に獲得したいもの
> - 各Actorにとって譲れない条件・レッドライン
> - 相手に対して持つLeverageと、実際には使いにくいカード
> - 公開発言と実際の行動・交渉ポジションにGapがあるか
> - Actor同士の目的がどこで一致し、どこで衝突しているか
> - 現局面を左右するPrimary Key Point
> - 最も蓋然性の高い方向性と代替シナリオ
>
> を分析してください。
>
> 「正常化する／しない」という二分法だけで考えず、各Actorが最終合意そのものではなく、
> 交渉プロセスから別の利益を得ようとしている可能性も検討してください。ただし、Evidenceの
> ない裏読みを主シナリオに採用しないでください。

## Case 3｜インドのロシア産原油購入と西側制裁

**評価上の狙い**: Distributed / Structural。首脳の意向だけで説明せず、精製業者、価格差、
金融・海運、米欧制裁制度、インド国内政治などの分散した力を拾えるか。Entity紐付けは意図的に
なし（首脳（Putin）へ分析が引き寄せられることを避け、分散構造の発見を自力にさせるため）。

> インドによるロシア産原油の購入と精製品輸出、それに対する米国・EU等の制裁・外交圧力を
> めぐる現在の局面について分析してください。
>
> 最新の公開情報を確認し、
>
> - インド政府、ロシア政府、米国政府、EU、インドの精製企業、海運・保険・金融などのうち、
>   実際に結果を動かす主体
> - 各主体の目的、制約、経済的インセンティブ、利用可能なカード
> - 原油価格差、決済、船舶、保険、制裁制度、精製後製品の扱い等のStructural / Institutional
>   要因
> - インド政府の外交的発言と実際の企業行動の関係
> - 西側による圧力がどこまで実効性を持つか
> - この局面のPrimary Key Point
> - 現在のMain ScenarioとAlternative Scenario
> - 方向転換を示すObservable Indicators
>
> を整理してください。
>
> 「インドはロシア寄り／西側寄り」という政治ラベルだけではなく、誰がどの条件下で行動を
> 変えるのかという意思決定構造を重視してください。
>
> Evidenceが主体別に不足している場合は、必要な追加Researchを行ったうえで判断してください。

## Case 4｜グリーンランドをめぐる米国・デンマーク・自治政府

**評価上の狙い**: Institution + Actor + Frame check。「米国対デンマーク」という国家間対立で
単純化せず、グリーンランド自治政府・住民、資源、安全保障、デンマーク王国の制度構造を拾える
か。10 Key ActorのうちTrumpが関与するため、entity紐付けあり（デンマーク政府・グリーンランド
自治政府は10人以外の新規主体として、意図的にentity紐付けなし）。

> グリーンランドをめぐる米国、デンマーク、グリーンランド自治政府の安全保障・資源・主権を
> めぐる現在の局面について分析してください。
>
> 最新の公開情報を確認した上で、
>
> - この局面で実際に意思決定力・拒否権を持つ主体
> - 米国、デンマーク政府、グリーンランド自治政府・主要政治勢力のそれぞれの上位目的
> - 安全保障、独立・自治、重要鉱物、北極航路、米軍プレゼンス、経済支援等の論点の関係
> - 各主体のLeverage、Constraint、Red Line
> - 法制度・自治制度・住民意思が、国家指導者の意図をどこまで制約するか
> - 現局面のPrimary Key Point
> - 主シナリオと代替シナリオ
> - 今後の方向性を変えるObservable Indicators
>
> を分析してください。
>
> 「米国がグリーンランドを欲している」「デンマークが拒否している」という国家間の表面的な
> フレームだけで十分かを検証し、グリーンランド自身の意思決定権や制度構造を踏まえることで
> 分析フレームそのものを変更すべきかも検討してください。
>
> ただし、Frame-breakingな説明を作ること自体を目的にせず、既存フレームで十分ならその理由を
> 示してください。

## Case 5｜台湾海峡の「封鎖／演習」認識

**評価上の狙い**: Evidence / Media divergence / Frame-breaking / Temporal。同じ中国の軍事
行動を、中国・台湾・米国・専門家・商業プレイヤーが違う意味で解釈するケース。Narrativeその
ものに引っ張られず、実際の能力・行動・商業影響をKey Pointにできるかを見る。Entity紐付けは
意図的になし（Chunk6の南シナ海ケースと同様、Media/Evidence判断を自力にさせるため）。

> 台湾海峡周辺における中国軍・海警局の最近の活動について、「軍事演習」「封鎖訓練」
> 「検疫・隔離」「実質的な封鎖準備」など異なる評価が出ている局面を分析してください。
>
> 最新の公開情報を調査し、
>
> - 中国指導部・人民解放軍・海警局、台湾政府、米国、日本等の主要主体
> - 各主体の目的、制約、利用可能なカード、避けたいエスカレーション
> - 中国側公式発表、台湾側評価、米国・日本政府、主要メディア、安全保障専門家などでNarrative
>   がどう異なるか
> - Narrativeの違いが単なる表現差なのか、異なるEvidenceやAudienceを反映しているのか
> - 実際に「通常の演習」と「封鎖能力の実証」を分けるObservableな要素
> - 現局面のPrimary Key Point
> - Main Scenarioと重要なAlternative Scenario
> - 商船、航空、保険、市場等に実質的影響が発生したと判断するためのIndicators
>
> を分析してください。
>
> 「封鎖」という強い言葉が報じられていること自体をKey Pointにせず、実際の軍事・法執行・
> 商業行動をEvidenceとして、局面の意味を判断してください。
>
> 既存の「軍事演習の強度が上がった」という説明では捉えられない変化がある場合に限り、
> Frame-breakingな解釈を提示してください。
