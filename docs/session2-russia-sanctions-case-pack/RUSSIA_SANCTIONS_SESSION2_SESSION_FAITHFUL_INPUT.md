# Interview Questions（5. 江口さんに聞きたいこと）

**①** GPTが設定したステークホルダーについて、抜けている主体、逆に重要度を下げてよい主体は
ありますか？
補足: 今回の局面を実際に「動かす／止める」力を持つのは誰か／国・政党・省庁など、どこまで
細かく分けて見る必要があるか／なぜその主体は分ける必要があるのか／逆に、どんな場合なら
まとめて見ても問題ないか

**②** GPTが整理した各主体の「目的・譲れないもの・カード・弱点」の理解で、違うところや
足りないところはありますか？
補足: 表向きの立場と、本当に実現したいことは同じか／カードは持っていても、実際には使えない
ものはないか／国内政治、支持基盤、経済、安全保障など何が制約になっているか／何を根拠に
そう判断しているか

**③** 実際にどの力が勝ったのか？なぜ？今回の局面を最も強く動かしたのは、誰のどんな力だった
と見ますか？
補足: 誰が誰に働きかけたのか／具体的にどんなカードを使ったのか／なぜ今回はそのカードが
効いたのか／そのカード単体が強かったのか、他主体との連携によって強くなったのか／複数の力が
働いている中で、なぜそれを「決定的」と判断するのか／起点となった力と、途中で増幅した力を
分けるとどうなるか

**④** 反対側はなぜ止められなかったのか？別の方向を望んでいた主体は誰で、なぜ今回の流れを
止められなかったのでしょうか？
補足: カード自体が弱かったのか／強いカードを持っていたが使えなかったのか／制度上の権限・
拒否権が足りなかったのか／他主体への依存が制約になったのか／coalitionを作れなかったのか／
国内政治・財政・世論など別の目的を優先せざるを得なかったのか／時間軸が不利だったのか

**⑤** GPTが置いた中心仮説・力学の読みについて、合っているところと、違うところはどこ
でしょうか？
補足: GPTが重く見すぎている要素は何か／逆に軽く見すぎている要素は何か／因果関係の向きを
間違えていないか／「AがBを動かした」と見ているが、実際には逆ではないか／GPTが間違って
いるなら、それは「情報不足」なのか「情報はあったが読み方を間違えた」のか／江口さんなら、
何を最初に見て仮説を修正するか

**⑥** 今回、GPTが江口さんと同じレベルで読むために不足していたものは、次のどこにありますか？
- A｜前提として持っておくべき知識: 主要人物・組織とその実質的な権限／政党・組織内部の勢力
  関係／支持基盤・産業との関係／主体間の依存関係／過去の協力・対立関係／各主体のレッドライン
  や過去の行動
- B｜今回の局面で追加確認すべき情報: 誰の発言・行動／票・予算・人事／政策変更／軍事・経済
  行動／非公式な人物関係／相手側の反応
- C｜情報をどう評価するかという判断ルール: どの主体を重要視するか／どのカードが実際に使える
  と判断するか／どのRelationshipを今回重要と見るか／どの力を支配的と判断するか／反対勢力に
  実際のBlocking Powerがあるか
- D｜過去の経験: 似た局面で誰がどう動いたか／同じカードを過去に使った結果／過去に妥協・
  撤回・方針転換した条件
