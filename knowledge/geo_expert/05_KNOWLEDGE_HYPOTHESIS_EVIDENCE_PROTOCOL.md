# Hypothesis & Evidence Protocol

## 1. 情報の分類

### Fact：確認済み事実
資料・一次情報・信頼できる出典から確認できる出来事、発言、数値。

### Official Claim：公式主張
政府、企業、組織、本人が主張した内容。真偽とは別に保存する。

### Observation：観測
実際の政策変更、撤回、現場行動、市場反応、投票、運用変化。

### Inference：分析上の推論
事実と観測を組み合わせた説明。

### Hypothesis：仮説
意図、Persistent Preference、Audience、内部力学、撤回理由、隠れた利害一致、次の行動など未確認の説明。

### Illustration：例示
思考法を説明する仮想例。

## 2. Persistent Preference仮説

Key Stakeholderの上位志向を仮説化する場合、単一の発言を根拠にしない。

最低限確認する：

- 複数の過去行動で繰り返されているか
- 発言だけでなく実際の選択・交渉行動と整合するか
- 異なる局面でも残る傾向か
- 反対事例があるか
- 役職・制度・相手の違いで説明できるか
- 現在の局面へそのまま適用してよいか

Persistent Preferenceは「人物の真実」ではなく、次の行動を読むための更新可能な仮説である。

## 3. 仮説カード

各仮説を次の形で整理する。

- 仮説名
- 説明する事象
- Key Stakeholder / 関連主体
- Persistent Preferenceとの整合
- Observed Actionとの整合
- Preference-Action Gapの説明
- Primary / Secondary Audience仮説
- 支持する事実・観測
- 弱める事実・観測
- 追加で必要な仮定
- 競合仮説
- 撤回条件
- 次に見る指標
- 確信度

## 4. 主シナリオの選択基準

現時点では、次を用いる。

1. より多くの観測を説明できる
2. Key StakeholderのPersistent Preference・主体目的と整合する
3. Persistent PreferenceとObserved Actionがずれる場合、そのGapを説明できる
4. 周辺ステークホルダー、Audience、政治・制度制約と整合する
5. 時系列と整合する
6. 不要な追加仮定が少ない
7. 競合仮説より反証に耐える
8. 次の観測可能な兆候を提示できる

これらは暫定基準であり、専門家レビューとA/B検証で更新する。

## 4.1 主シナリオの表現ルール

主シナリオは、複数仮説の中で現時点で最も説明力が高い中心仮説として提示する。確定事実のようには書かないが、根拠がある場合は曖昧化しすぎない。

推奨表現：

- 現時点では、〇〇と見るのが最も整合的である。
- 提供資料の範囲では、〇〇を主シナリオとして置く。
- 〇〇の可能性も残るが、現在の材料からは△△を主軸に見る。

避ける表現：

- 〇〇の可能性があるが、△△の可能性もあり、□□の可能性もある。
- いずれの可能性も否定できない。
- 今後の動向を注視する必要がある。

これらの表現が必要な場合でも、それだけで終わらせず、主シナリオ、根拠、反証条件を示す。

## 5. Preference-Action Gapの検証

上位志向と今回行動が反対に見える場合、次を競合仮説として検証する。

- Persistent Preference自体が誤っている
- 優先順位が変化した
- Audience向けのSignalingである
- 支持基盤・選挙・党内政治による制約
- 議会・制度・官僚組織による制約
- 相手国・同盟国からの圧力
- 経済・市場コストによる制約
- 交渉カードとして一時的に逆方向へ動いている

最初から「本音と建前」と決めつけない。複数説明を比較する。

## 6. Signal / Substanceの検証

発言や政策の本気度を読む場合、Audience仮説とAction Substanceを分ける。

確認する情報：

- 実際の対象・適用範囲
- 拘束・強制性
- 例外・裁量余地
- 実施・執行状況
- 予算・人員・制度等のコミットメント
- 行動に伴う本人・組織のコスト
- 過去の同種措置との比較

定量スコアを機械的に作るのではなく、どの要素を重く見たかを説明する。

## 7. 反証プロトコル

主シナリオを出す場合、主張を弱めるのではなく、最低限次を示して支える。

- 支持材料
- 最も強い反論
- 競合する説明
- Persistent Preference仮説を弱める事例
- Audience仮説を弱める事例
- 主シナリオを弱める情報
- 主シナリオを撤回する条件
- 現時点で答えられない点

反証条件が置けない仮説は、確信度を下げる。

## 7.1 代替仮説の扱い

代替仮説は、主シナリオを曖昧にするためではなく、検証可能性と更新可能性を確保するために示す。

- なぜ現時点では主シナリオではないのか
- どの材料が出れば強まるのか
- どの材料が出れば弱まるのか
- どの条件で主シナリオから切り替えるのか

## 8. 確信度

### 高
複数の信頼できる事実・行動が整合し、競合説明が弱い。

### 中
一定の証拠はあるが、意図・Persistent Preference・Audience・内部力学に未確認部分がある。

### 低
限定的材料に基づき、競合説明も十分成立する。

### 判断不能
基礎事実または重要主体の情報が不足している。

## 9. 調査の設計

調査は、関連情報を大量に集めることではない。仮説を検証・反証する問いへ分解する。

- この局面を実際に動かせるのは誰か
- Key Stakeholderの過去の類似行動は何か
- その人物の上位目的仮説を支持・反証する事例は何か
- 今回のObserved Actionは過去パターンから逸脱しているか
- 誰に見せることが政治的に最も合理的か
- 支持基盤、選挙区、献金、産業、雇用はどうつながるか
- 誰が発言・政策へ反発したか
- 発言後にどの組織が動いたか
- 現場で実施されたか
- 相手はどの強度で反応したか
- 対象品目・企業・地域は何か
- 誰が利益を得て、誰が損をするか
- 選挙・交渉期限までに何が必要か
- 何が出れば現在の見立てが崩れるか

## 10. 専門家質問

質問は次を含める。

1. 具体的事象
2. 確認済み事実
3. Key StakeholderとPersistent Preferenceの暫定仮説
4. 今回行動とのGap
5. 確認したいAudience・内部力学
6. 仮説が間違っている可能性
7. 次に見るべき兆候

専門家のコメントを権威づけのためだけに使わない。根拠、アクセス範囲、別説明も確認する。

## 11. ソースの扱い

優先順位の目安：

1. 一次情報・公式文書・発言原文
2. 現場に近い信頼できる報道・現地メディア
3. 複数の信頼できる報道による確認
4. 専門家、研究者、情報ベンダーの分析
5. 専門家・分析者が継続的に参照するSource of Sources
6. 社内情報・自社エクスポージャー
7. AIが生成した仮説

公式情報は公式立場を示すが、真の目的を証明するとは限らない。資料間の矛盾は隠さず、判断への影響を示す。

主流ナラティブと異なる情報は、それだけで信頼度を上げない。差分をInvestigation Triggerとして使い、一次情報・別ソースで裏取りする。

## 12. メディア編集意図の扱い

Selection、Placement、Prominence、Framing、Omissionは分析上のObservationになり得るが、編集意図そのものはInference / Hypothesisである。

紙面の位置、面積、テレビでの順序等が取得できない場合は推測しない。デジタル記事だけから「トップ扱いだった」等を作らない。
